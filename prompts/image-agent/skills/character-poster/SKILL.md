# 角色主视觉海报

## 适用与不适用

用于角色是绝对核心的海报、立绘、英雄视觉、人物情绪肖像与角色宣传图。需要同时处理身份辨识、姿态、表情、服装轮廓、镜头距离和世界观线索。不用于商品 campaign，也不替代局部编辑；如果用户在既有角色图上只改眼睛颜色、服装或背景，应由 `local-image-edit` 主导并把本 skill 作为身份约束参考。

## 专业 brief

提取 `characterIdentity`、`ageRange`、`silhouette`、`facialFeatures`、`hair`、`outfit`、`pose`、`expression`、`camera`、`environmentClues`、`lighting`、`palette`、`continuityAnchors`、`copyPolicy`。参考图存在时要区分借角色身份、借服装、借画风还是只借姿态，不能默认全部复制。涉及真人时描述可见特征，不擅自推断敏感身份。

## 信息充分度与追问

角色身份和一个情绪/动作维度已知即可生成基线。只有“做个角色海报”时问角色是谁，以及想让他呈现什么情绪或力量感。已有上传角色图时不重复问外貌，优先问这张海报是要突出人物身份、战斗状态还是剧情情绪。用户要求系列海报时，将不变的身份锚点写进每个 task。

## assistantReply 风格

说明会保留哪些身份特征，并点出姿态、镜头和光线如何共同表达角色。不要只复述“酷、飒、强”。如果输入不足，问一个能决定轮廓和情绪的关键问题；如果是概念角色，说明先按当前设定建立第一版身份锚点。

## generation.prompt 模板

英文 prompt 顺序：角色身份与不可变特征 → 表情和心理状态 → 姿态与手部动作 → 服装、材质和关键道具 → 镜头距离、焦段、角度 → 场景中的世界观线索 → 主光、轮廓光和色彩 → 海报层级与文案留白 → 一致性约束。避免同时堆叠互相冲突的画风。参考角色时明确 `preserve the same facial identity, body proportions, hairstyle and signature outfit details`。

## 正例、反例与质量检查

正例：“把这个女战士做成低机位英雄海报，保留盔甲和脸”应引用角色图并另起海报。“做一张疲惫侦探的雨夜情绪肖像”可直接生成。反例：“给护肤品做女性代言主视觉”更偏品牌/商品海报；“只把上一张头发变短”是局部编辑。

检查脸、体型、发型和标志性服装是否稳定；姿态是否符合情绪；手部和道具是否合理；背景是否提供世界观但不抢角色；光线是否塑造轮廓；文字区是否不压住脸与关键动作。
