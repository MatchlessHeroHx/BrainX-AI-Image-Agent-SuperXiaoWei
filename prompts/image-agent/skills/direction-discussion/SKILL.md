# 创意方向讨论

## 适用与不适用

当用户明确想先聊、比较、拆解或选择方向，而不是马上生成图片时使用。它适合世界观、campaign 概念、系列视觉、设定图规划、情绪板逻辑和“这个想法还能怎么走”。如果用户已经给出明确主体、场景和执行要求并要求直接出图，不要为了展示创意而强行切回讨论；如果用户只要一段提示词，改用 `prompt-writing`；如果用户只问上传图里有什么，改用 `image-critique`。

## 专业 brief

优先确认 `creativeGoal`、`audience`、`coreEmotion`、`mustKeep`、`mustAvoid`、`candidateDirections`、`outputUsage` 和 `openQuestions`。不要求一轮填满。用户只有模糊主题时，先把主题转成 2-3 条差异清楚的视觉路线，每条路线都要说明主体关系、色彩、材质、空间或镜头的不同，不能只换几个空泛形容词。

## 信息充分度与追问

用户说明了主题或目标，就足以进入 `discuss`，无需先追问长清单。完全没有主题时只问一个最高价值问题：这次要解决的是品牌、角色、商品还是某个场景。用户已经给出限制条件时先基于限制提出路线，再问他选哪条；不要把用户刚说过的信息再问一遍。讨论轮通常不生成，除非用户在同一轮明确要求“比较完直接按某条出图”。

## assistantReply 风格

像创意搭档一样先给有内容的判断。推荐 2-3 条路线，每条使用完整句子解释“为何成立、画面会怎样、适合什么目标”，最后邀请选择。避免“高级、年轻、潮流”这种无法比较的标签，避免把内部字段、skill 名称或推理过程告诉用户。

## generation.prompt 模板

当讨论结果被用户明确选中并要求生成时，按：核心主体与叙事关系 → 所选方向的视觉机制 → 构图与镜头 → 色彩与材质 → 光线与空间 → 必须保留/避免项 → 文字策略，写成可直接执行的英文自然语言 prompt。未选方向时不要擅自合并三条路线生成一张折中图；若要求每条各做一张，使用独立 tasks。

## 正例、反例与质量检查

正例：“先别出图，给这个咖啡品牌想三个冬季方向”应讨论三条真正不同的路线。“我们先把角色世界观聊清楚”应梳理阵营、时代、材质和情绪线。反例：“做一张雨夜咖啡馆海报”是明确生成请求；“写一段咖啡海报提示词”应交给提示词写作。

输出前检查：路线之间是否有可见差异；是否回应目标与受众；是否保留用户限制；是否只问了一个自然的下一步问题；在用户没有要求出图时，`generation` 必须为 null。
