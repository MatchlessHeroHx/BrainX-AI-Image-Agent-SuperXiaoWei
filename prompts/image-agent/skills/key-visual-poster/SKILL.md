# 品牌主视觉海报

## 适用与不适用

用于需要承担传播任务的主视觉、campaign 海报、发布会视觉、活动页头图、社媒封面与品牌 KV。核心不是“画面好看”，而是第一眼信息层级、主记忆点、品牌语气和后续裁切适配。不用于以人物设定和角色气质为核心的角色海报，也不用于纯商品 listing 主图；用户只想讨论多个方向时可与 `direction-discussion` 同时作为候选，但最终行动应尊重“先聊还是直接做”。

## 专业 brief

提取 `campaignGoal`、`brandTone`、`audience`、`heroSubject`、`keyMessage`、`copyPolicy`、`format`、`channel`、`visualHierarchy`、`negativeSpace`、`mustKeep`。主体、标题区和辅助信息要有明确优先级。用户没有提供品牌资产时，不要擅造 logo；没有指定文案时默认预留清晰文字区，而不是让模型生成乱码。

## 信息充分度与追问

有传播主题和主角即可先生成基线。只有“做个活动海报”且没有活动内容时，问活动是什么以及最想让人记住什么，最多两个问题。已知活动、受众和调性但没给尺寸，可根据语境提出一个合理构图，并让比例留在参数表单确认。用户要求多个渠道时，先确定一个母版视觉逻辑，再为每个比例描述安全区，不要把所有比例挤进同一 prompt。

## assistantReply 风格

回复中说明第一视觉主体、记忆点与文案留白会如何安排，让用户知道海报为何能传达主题。不要以设计术语堆砌专业感，也不要声称“保证转化”。信息不足时用自然语言询问活动主题和核心信息，不发问卷。

## generation.prompt 模板

按以下顺序写英文 prompt：campaign/活动目标与受众 → hero subject 与视觉隐喻 → 信息层级和构图 → 标题/文案安全区 → 品牌色与辅助色 → 材质、光线和空间 → 渠道裁切要求 → 禁止项。指定文字必须精确引用；未指定文字时写 `clean reserved headline area, no fabricated logo or unreadable text`。海报必须有一个主焦点，避免平均铺满元素。

## 正例、反例与质量检查

正例：“给新品发布会做一张未来感主视觉，右侧留标题区”应直接生成并明确主体层级。“先给咖啡节 KV 想三个方向”应先讨论。反例：“画一个末日女战士角色海报”优先角色 skill；“Amazon 白底主图”属于电商图。

检查是否一眼能看出主次；是否有真实可用的文案区；是否没有乱造品牌文字；光线与材质是否服务主题；构图是否能适配目标渠道；prompt 是否把“高级感”等词转成具体视觉机制。
