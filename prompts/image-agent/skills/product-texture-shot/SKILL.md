# 商品材质棚拍

## 适用与不适用

用于不以平台 listing 规范为第一目标的商业产品棚拍、材质广告图、静物 packshot、微距细节与概念产品摄影。重点是让金属、玻璃、磨砂塑料、液体、皮革、织物或食品表面被光线“解释出来”。Amazon/淘宝主图、详情卖点与 A+ 流程优先 `ecommerce-product-image`；若只是把现有产品图局部改色，优先 `local-image-edit`。

## 专业 brief

提取 `productIdentity`、`materialFocus`、`shotScale`、`cameraAngle`、`surfaceCondition`、`lightingSetup`、`background`、`props`、`commercialMood`、`referenceMode`、`copyPolicy`。真实商品有参考图时，必须把外形、颜色、接口、标识位置和比例视为身份约束；无参考图时要在回复中说明按概念产品处理，避免让用户误以为能还原真实 SKU。

## 信息充分度与追问

产品和要强调的材质已知即可生成。只说“做个产品质感图”时，优先问是什么产品以及最想表现哪种材质。用户上传清楚产品图后不再问产品是什么，只确认要做整体棚拍还是局部 macro。背景、镜头或道具可按商业目的给出基线，不用把所有摄影参数都抛给用户。

## assistantReply 风格

用一两句具体说明会怎样布光、为什么这种光能呈现目标材质，以及哪些产品身份会保持不变。避免“极致高级、电影级、8K”等空词。无参考图时直说“先按概念款做”，有参考图时说明优先保持轮廓和关键结构。

## generation.prompt 模板

英文 prompt 顺序：产品身份与几何结构 → shot scale/角度/镜头 → 材质微表面 → 主光、补光、轮廓光及反射控制 → 台面与背景 → 道具关系 → 商业情绪与留白 → 文字/水印限制。金属要写拉丝方向、边缘高光和反射软硬；玻璃要写透射、折射和受控高光；磨砂塑料要写柔散射；液体与食品要写黏度、新鲜度、切面或凝露，而不是只写 texture。

## 正例、反例与质量检查

正例：“给这瓶香水做一张玻璃折射和金属瓶盖的棚拍”应使用参考并生成。“做一个耳机磨砂塑料的微距广告图”应明确 macro 与侧向掠射光。反例：“用耳机图做 Amazon 白底主图”属于电商图；“把瓶盖改成金色”是局部编辑。

检查产品是否是第一主体；材质是否由具体光线解释；真实产品身份是否稳定；道具是否抢戏；高光是否可信；是否没有无意义质量词、乱加文字或伪造 logo。
